# 7. Centro de diagnóstico

Si algo no funciona, este apartado te ayuda a comprobar la conexión y el estado de la base de datos.

- Pulsa **Revisar estado** para lanzar una serie de pruebas automáticas.
- Verás si la conexión con Supabase está activa y si las tablas clave responden.
- También muestra métricas técnicas por si soporte necesita detalles.

- 📸 *Captura del Centro de diagnóstico*

> 🆘 Úsalo cuando notes lentitud, errores de conexión o para reportar incidencias al equipo nacional.
