# 0. Manual de MCM Bank

Bienvenido 👋. Aquí encontrarás cómo aprovechar al máximo la aplicación que usamos en las Delegaciones Locales del Movimiento Consolación para el Mundo.

La app está pensada para que podamos llevar la economía de forma **transparente, rápida y cómoda**. Desde cualquier dispositivo podrás:

- Registrar ingresos y gastos de tu MCM Local.
- Asignar cada movimiento a una categoría común.
- Importar datos directamente del Sabadell o CaixaBank.
- Analizar el balance de cada actividad y sacar memorias económicas sin quebraderos de cabeza.

> ☁️ Todos los datos se guardan en la nube, de forma segura y sin tocar directamente la banca online.

En este manual te explicamos paso a paso cada apartado. Si ves un icono de cámara, ¡es momento de añadir una captura de pantalla!
