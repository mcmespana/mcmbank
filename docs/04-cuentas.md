# 4. Cuentas

Aquí gestionas las cuentas bancarias y las cajas de efectivo de tu Delegación Local.

- Verás el saldo calculado según los movimientos registrados.
- 📸 *Captura del listado de cuentas*

## Crear una cuenta

1. Entra en **Cuentas** y pulsa **Nueva cuenta**.
2. Elige si es una cuenta bancaria o una caja.
3. Añade nombre, IBAN (si procede) y personas autorizadas.

## Editar o eliminar

- Usa los iconos ✏️ para editar o 🗑️ para borrar.
- Si copias el IBAN se marcará con un mensaje verde ✅.

> 💡 Puedes usar colores para distinguir rápidamente cada cuenta.
