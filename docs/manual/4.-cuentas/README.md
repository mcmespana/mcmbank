# 4. Cuentas

:moneybag: Verás el saldo calculado **según los movimientos registrados.**&#x20;

<figure><img src="../../../.gitbook/assets/Captura de pantalla 2025-09-18 a las 19.03.46.png" alt="" width="563"><figcaption></figcaption></figure>

> **OJO** :eyes: El saldo puede no coincidir con el del banco, se calcula con los ingresos y los gastos registrados en la aplicación.
>
> Es una _'buena práctica'_ asegurar que los saldos coinciden con el banco tras revisar unos cuantos movimientos

## Crear una cuenta

1. Entra en **Cuentas** y pulsa **Nueva cuenta**.
2. Elige si es una cuenta bancaria o una caja.
3. Añade nombre, IBAN (si procede) y personas autorizadas.

<figure><img src="../../../.gitbook/assets/Captura de pantalla 2025-09-18 a las 19.04.29.png" alt="" width="371"><figcaption></figcaption></figure>

## Editar o eliminar

* Usa los iconos ✏️ para editar o 🗑️ para borrar.
* Si copias el IBAN se marcará con un mensaje verde ✅.+

<figure><img src="../../../.gitbook/assets/Captura de pantalla 2025-09-18 a las 19.05.07.png" alt="" width="344"><figcaption></figcaption></figure>

> 💡 Puedes usar colores para distinguir rápidamente cada cuenta.&#x20;
>
> Si en banco pones 'Caixabank' o 'Sabadell' saldrá el logo. Hay un icono para diferenciar el dinero en efectivo de los bancos.
