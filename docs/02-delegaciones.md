# 2. Delegaciones Locales

Al iniciar sesión verás un selector en la parte superior para elegir tu **MCM Local**.

- Usa el buscador para encontrar tu delegación.
- Cambia de delegación en cualquier momento y la app actualizará los datos al instante.
- 📸 *Captura del selector de delegación*

> 🏢 Sólo verás las delegaciones donde tengas permisos. Si falta alguna, contacta con coordinación nacional.
