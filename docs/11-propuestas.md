# 11. Propuestas de mejora

"¿Por qué no mejoramos esto?" — el espacio para compartir ideas y reportar errores entre todas las delegaciones.

📸 _Captura del panel de Propuestas_

## Compartir una idea o reportar un error

{% tabs %}
{% tab title="💡 Compartir idea" %}
Botón **"Compartir idea"**. Escribe un título breve (por ejemplo, *"Cambiar este filtro, añadir botón para..."*) y, si quieres, más detalles. Pulsa **"Publicar propuesta"**.
{% endtab %}

{% tab title="🐛 Reportar error" %}
Botón **"Reportar error"**. Describe qué falla (por ejemplo, *"Error al descargar extracto..."*) con el máximo detalle posible para que se pueda reproducir. Pulsa **"Reportar error"**.
{% endtab %}
{% endtabs %}

{% hint style="info" %}
Cualquier persona con sesión iniciada puede crear propuestas, votar y comentar — no hace falta ningún rol especial.
{% endhint %}

## Cómo avanza cada propuesta

| Ideas | Errores |
|---|---|
| Nueva idea | Error detectado |
| En estudio | Resolviendo |
| Lo haremos | Resuelto |
| En desarrollo | |
| Hechísimo 🎉 | |

{% hint style="warning" %}
🔐 Solo un administrador puede cambiar el estado de una propuesta. El resto de personas ven el estado actual, pero no pueden modificarlo.
{% endhint %}

Las propuestas ya completadas ("Hechísimo") se ocultan por defecto para no saturar la vista; un botón **"Mostrar hechísimos"** las vuelve a mostrar.

## Votar y comentar

- 👍 Vota una idea o error para mostrar que también te interesa (para errores, el botón se llama **"También me pasa"**). Puedes retirar tu voto en cualquier momento.
- 💬 Comenta para dar contexto, aportar detalles o preguntar. Se abre una conversación con todos los comentarios de esa propuesta, ordenados por fecha.

📸 _Captura de una propuesta con votos y comentarios_

{% hint style="success" %}
💡 Las propuestas se ordenan por número de votos, así que las que más apoyo tienen suben solas a lo más visible.
{% endhint %}
