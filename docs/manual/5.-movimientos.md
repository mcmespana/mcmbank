# 5. Movimientos

* Podrás **ver los movimientos** ordenados cronológicamente
* Asignar **categorías** a los movimientos
* Editar el **concepto** haciendo click en la parte en negrita
* Editar **todos los datos** del movimiento haciendo el click en el resto de espacios
* Puedes ver la lista, filtrar, editar o crear nuevos

<figure><img src="../../.gitbook/assets/Captura de pantalla 2025-09-18 a las 19.05.32.png" alt="" width="563"><figcaption></figcaption></figure>

* Puedes verlos en lista, filtrarlos, editarlos o crear nuevos.

## a) Añadir un movimiento a mano

1. Desde cualquier página, usa el atajo **Acciones rápidas → Crear movimiento** o el botón ➕ en Movimientos.
2. Completa concepto, importe (positivo para ingreso, negativo para gasto), fecha y cuenta.
3. Selecciona una categoría y añade notas si quieres.
4. Guarda para que aparezca en la lista.

<figure><img src="../../.gitbook/assets/Captura de pantalla 2025-09-18 a las 19.06.30.png" alt="" width="375"><figcaption></figcaption></figure>

> 📝 La app valida que los campos obligatorios estén completos antes de permitir guardar.

{% hint style="success" %}
💾 Los cambios se guardan automáticamente después de unos segundos.
{% endhint %}

## b) Importar un excel del banco

{% hint style="warning" %}
Si tienes cuenta del Sabadell se **importa automáticamente**
{% endhint %}

<figure><img src="../../.gitbook/assets/Captura de pantalla 2025-09-18 a las 19.06.53.png" alt="" width="375"><figcaption></figcaption></figure>

Si tienes muchos movimientos, puedes importarlos de una vez:

{% stepper %}
{% step %}
#### Abre el importador

Pulsa **Importar** en Acciones rápidas o desde Movimientos.
{% endstep %}

{% step %}
#### Elige cuenta y origen

Selecciona la cuenta destino y el formato del archivo.
{% endstep %}

{% step %}
#### Sube el archivo y revisa

Arrastra el archivo, sigue el asistente y revisa los duplicados detectados antes de confirmar.
{% endstep %}
{% endstepper %}

{% tabs %}
{% tab title="🟦 Sabadell" %}
Exporta el extracto en Excel/CSV desde la banca online del Sabadell y súbelo tal cual — el importador reconoce su formato automáticamente.

{% hint style="success" %}
Si tu cuenta del Sabadell ya está **conectada con Enable Banking** (capítulo 4), no necesitas importar nada: los movimientos entran solos cada noche.
{% endhint %}
{% endtab %}

{% tab title="🟧 CaixaBank" %}

{% endtab %}
{% endtabs %}

{% hint style="info" %}
⏱️ Después de importar refrescamos los datos automáticamente para que veas los nuevos movimientos al momento.

## c) Editar el movimiento&#x20;

Toca cualquier movimiento de la lista para abrir su ficha detallada:

* Cambia la categoría, el contacto, la descripción o la fecha.
* Modifica el importe con confirmación.
* Adjunta archivos (facturas, justificantes, etc.).

> 💾 Los cambios se guardan automáticamente después de unos segundos.

## d) Adjuntar archivos

Una práctica muy recomendable es **guardar las facturas directamente en MCM Bank**

Si entras en el detalle de edición de un movimiento puedes

* Presionar el botón 'Archivos'
* Subir archivos de tipo 'factura'
* Subir archivos de tipo 'otro' (justificantes de pago, un ticket, otra cosa...)&#x20;

<figure><img src="../../.gitbook/assets/Captura de pantalla 2025-09-18 a las 19.07.36.png" alt="" width="375"><figcaption></figcaption></figure>

* Adjunta archivos (facturas, justificantes, etc.) — si adjuntas una factura, se crea sola en **Facturas** (capítulo 7).
* Marca **"Falta factura"** si este movimiento debería llevar una y todavía no la tiene.

{% hint style="info" %}
La marca de "Falta factura" **se quita sola** en cuanto le vinculas una factura, así que no tienes que acordarte de repasarla. En la lista verás un icono azul de recibo 🧾 en los movimientos que ya tienen factura, y el triángulo ámbar ⚠️ solo en los que la esperan.
{% endhint %}

## e) Trabajar con varios movimientos a la vez

Pasa el ratón por encima de un movimiento (o tócalo en el móvil) y pulsa el círculo de la izquierda para seleccionarlo. Con **Shift + clic** en otro círculo seleccionas todo el rango de golpe.

Con algo seleccionado aparece una barra arriba con lo que puedes hacer sobre todos a la vez:

* **Editar categoría** — asignar la misma actividad a todos.
* **Unificar concepto** — poner el mismo texto en todos (útil tras una importación con conceptos del banco distintos para lo mismo).
* **Añadir nota** — añade un texto al final de la descripción de cada uno, sin borrar lo que ya hubiera.
* **Falta factura** — marca de una vez todos los que esperan papel. Es la forma rápida de repasar el extracto de un mes. Los que ya tienen factura vinculada se saltan solos. Si todo lo seleccionado ya estaba marcado, el botón cambia y sirve para quitar la marca.
* **Eliminar** — borra todos los seleccionados.

Mientras se aplica verás una barra de progreso con cuántos lleva, porque con muchos movimientos tarda unos segundos.

{% hint style="success" %}
**Si eliminas sin querer, hay vuelta atrás.** Tras un borrado en lote aparece un aviso con un botón **Deshacer** durante unos segundos: los movimientos vuelven tal cual estaban. Lo único que no se recupera son los archivos que tuvieran adjuntos.
{% endhint %}

{% hint style="warning" %}
Si cambias un filtro, la selección se vacía y te avisa. Es a propósito: la habías hecho sobre otra lista y no sería la misma.
{% endhint %}

## f) Exportar a Excel

Para trabajar los datos fuera de la app:

1. Abre la pantalla de **Movimientos**.
2. Pulsa el botón de **Descargar** ⬇️.
3. Se generará un archivo Excel con los movimientos filtrados.
4. Si la descarga se completa verás un aviso en verde.
