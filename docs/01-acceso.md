Para entrar a la aplicación necesitas una cuenta de MCM Bank. Aquí te explicamos cómo iniciar sesión o registrarte si es tu primera vez.

{% endhint %}

## Crear una cuenta

Si todavía no tienes acceso:

1. Desde la pantalla de inicio toca **"Solicítala desde aquí"**.
   - 📸 _Captura del enlace de registro_
2. Rellena tu email y una contraseña segura.
3. Confirma desde el correo que recibirás y ¡listo!

{% hint style="warning" %}
🔐 El acceso se concede a través de tu Delegación Local. Si tras registrarte no ves ninguna delegación o algún dato, habla con tu responsable o con **Configuración** (capítulo 12) para que te den de alta con el rol correcto.
{% endhint %}
