# 2. Delegaciones Locales

Al iniciar sesión verás un selector en la parte superior para elegir tu **MCM Local**. Toda la app —movimientos, cuentas, categorías, informes— se filtra según la delegación activa.

- Usa el buscador para encontrar tu delegación.
- Cambia de delegación en cualquier momento y la app actualizará los datos al instante.
- La última delegación elegida se recuerda para la próxima vez que entres.

📸 _Captura del selector de delegación_

{% hint style="info" %}
🏢 Solo verás las delegaciones donde tengas una membresía asignada. Si falta alguna, pide a un **Gestor Central** que te añada desde **Configuración** (capítulo 12).
{% endhint %}
