# MCM Bank - Guía

## ¿Qué es MCM Bank?

{% hint style="success" %}
Una App-Web está pensada para que podamos llevar la economía de forma **transparente, rápida y cómoda**. Desde cualquier dispositivo podrás...
{% endhint %}

{% stepper %}
{% step %}
### Registrar ingresos y gastos

Podrás añadirlos a mano o importar directamente los datos del Sabadell o Caixabank. Cada movimiento va asociado a una 'cuenta' (banco o dinero en caja)
{% endstep %}

{% step %}
### Asignar cada movimiento a una categoría

Por actividades o categorías genéricas&#x20;
{% endstep %}

{% step %}
### Análisis

Al final de cada actividad podrás analizar el balance de ingresos y gastos
{% endstep %}

{% step %}
### Memorias económicas

A final del curso tanto a nivel local como desde el ECE podrás extraer una sencilla memoria económica que podrás presentar en asamblea o te ayude a ver la situación económica de tu MCM
{% endstep %}
{% endstepper %}

> ☁️ Todos los datos se guardan en la nube, de forma segura y sin tocar el banco online, es como una 'copia' de los datos que hay en el banco, por lo que no hay ningún riesgo.
