# 6. Panel de Control

Nada más entrar verás el Dashboard, un resumen rápido de la situación económica de tu Delegación Local.

- 📸 *Captura del Dashboard*

Desde aquí también puedes acceder a las **Acciones rápidas**: ver movimientos, crear uno nuevo, importar o añadir una categoría.

## Resumen financiero

Este bloque muestra las cifras clave del periodo elegido:

- **Ingresos** 🟢
- **Gastos** 🔴
- **Balance** (ingresos menos gastos)
- **Transacciones** totales
- **Sin categorizar** para detectar pendientes

Toca cualquier tarjeta para ir directamente al listado correspondiente.

- 📸 *Captura del resumen financiero*

## Balance de actividad

Compara ingresos y gastos en un gráfico de barras:

1. Elige el periodo (mes, trimestre, curso…).
2. Filtra por una o varias categorías.
3. Observa cómo evoluciona el balance día a día.

- 📸 *Captura del gráfico de balance*

> 📉 Si no hay movimientos en el periodo seleccionado, te sugerimos limpiar los filtros.

## Análisis por categorías

Descubre cuánto se ingresa y gasta en cada categoría mediante gráficos de tarta y una tabla resumen.

1. Selecciona el periodo y, si quieres, limita a ciertas categorías.
2. Consulta los porcentajes y cantidades de ingresos y gastos.
3. Revisa la tabla para ver los totales de cada etiqueta.

- 📸 *Captura del análisis por categorías*

> 🔍 Este informe es ideal para preparar las memorias económicas de forma rápida.
